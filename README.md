# 📚 A+ Certification

The CompTIA A+ certification consists of two exams:

| Exam                  | Focus                                                                                             |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| **Core 1 — 220-1201** | Hardware, networking, mobile devices, cloud, virtualization, and hardware/network troubleshooting |
| **Core 2 — 220-1202** | Operating systems, security, software troubleshooting, and operational procedures                 |

Both exams must be passed to earn the A+ certification.

# 📖 How Each Lesson Will Work

Every major topic will follow the same structure.

## 1. Learn

Beginner-friendly explanation of the concept.

## 2. Know

The facts required for the A+ exam.

## 3. Understand

Explain **why** the technology works.

## 4. See It

Diagrams, examples, screenshots, and visual explanations.

## 5. Apply It

A real-world IT scenario.

## 6. Practice

Practice questions.

## 7. Lab

Hands-on exercise.

## 8. Review

Quick summary and key points.

# 🎯 Study Philosophy

The goal isn't:

> **"Memorize enough answers to pass."**

The goal is:

> **"Understand the technology well enough to troubleshoot it."**

Every topic should answer three questions:

### What is it?

Understand the technology.

### How does it work?

Understand what happens behind the scenes.

### How do I troubleshoot it?

Know how to diagnose the problem.
